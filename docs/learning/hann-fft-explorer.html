Why two images?

A single image has position. A pair reveals how the same visual pattern shifted over time.

Why nine patches?

One convincing patch can be wrong for the whole scene. The estimator checks whether multiple regions agree.

This is an offline replay of the estimator on recorded images. The final State/browser stage illustrates what the existing code would publish; it is not a saved live HTTP response.

1 / 8 · recorded inputs

Two camera observations become small grayscale arrays

camera_command() / capture()
Camera recording: 1280 × 720 MJPEG → decoded and reduced to 320 × 180 grayscale for this offline example.

In live mode, FFmpeg makes the small frame when detection is off. With detection on, FFmpeg supplies full grayscale and OpenCV resizes a copy for motion. The OpenCV two-thread setting is shared processing configuration, not a separate resize worker.

Subtract each mean, then taper every patch edge

patch_shift() · Hann

Signed display: middle gray = zero after mean subtraction; darker = below mean; brighter = above mean. This changes numbers before FFT, not the camera exposure.

4 / 8 · Fourier comparison

Each weighted image becomes many spatial pattern coefficients

np.fft.fft2() / conjugate

These maps come from the two recorded, fully Hann-weighted patches. Their display centers zero frequency; the estimator's arrays remain in NumPy's original order.

Magnitude says how strongly a spatial pattern appears. Phase describes its alignment. The phase comparison keeps displacement information; the next step turns it into candidate-shift scores.

5 / 8 · inverse transform

Every correlation cell proposes a displacement

np.fft.ifft2()

Positive dx means image content moved right; positive dy means down. The correlation grid's coordinates describe proposed motion, not where the bright object sits on the screen.

6 / 8 · trust and precision

Inspect the peak, exclude its neighborhood, refine below one pixel

peak quality / refine()

Q measures peak prominence relative to background variation, not probability. A patch also fails if |dx| > 20 or |dy| > 14 analysis pixels.

7 / 8 · scene consensus

One strong patch is only one vote

image_shift()

All nine regions are tried independently. The code first needs four valid patch estimates, then at least four close to the median. If fewer than four remain, it returns None.

8 / 8 · shared state and display

publish_result() stores a reliable shift—or an unreliable status

What State would store

When snapshot() is requested while the camera result is fresh, the browser receives the latest image and status. It draws an exaggerated direction arrow only for motion="reliable".
Detector boxes and IMU rates are separate independently timed fields in the real snapshot; this recording does not supply synchronized values for them.

EdgeXR learning · start here

How the program works

EdgeXR is a camera head on a Raspberry Pi 4 that is learning to know the space around it: what it has seen, in which direction, and what it should expect when it turns back. It is also a deliberately realistic workload for learning how software uses a processor, before moving parts of it onto an FPGA.

The two-week plan (16 Nov 2026)

Five steps to a spatially aware head planned

Goal: the head sees a bottle, looks away, and while turning back says where the bottle should reappear, then reports same object as expected, missing or moved; it also knows which objects are nearer. Each step is chosen for the processor question it adds. See the decision and plan.

How to read the pages

Every number says where it came from

measured

Recorded on the Pi in a named run, with a linked result file in benchmarks/results/.

derived

Calculated from measured or configured numbers (for example, angles from the calibration). Correct arithmetic, but not itself timed or observed.

illustrative

A teaching drawing or simulation. Useful for intuition; never evidence.

planned

Not built yet. Shown so you can see where each existing piece is going.
